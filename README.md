A make.fun entry for "Unsent: The Micro-Confession Sprint" — one micro-confession in exactly two parts: a `To:` line naming who it was meant for, and the unsent message itself, one line exactly as typed.

## The entry

> To: Rani, my old friend
>
> I never thanked you for sitting next to me on the bus every morning after Dad left — I was too scared to say it out loud in case you stopped sitting there.

179 characters, 2 lines. A thank-you that never got said: not because it wasn't felt, but because saying it out loud felt like risking the one small kindness that was keeping the mornings bearable — the seat beside him on the bus.

## Run it

```sh
python3 main.py
```

`main.py` (Python stdlib only) verifies the entry against the gate in RULES.txt — UTF-8 text, 1 to 260 characters, not only white space, exactly two parts (a `To:` line and one message line) — then writes it to `/output/entry.txt`.
